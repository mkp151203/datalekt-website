# Archive

Kept for reference; nothing here is built or published.

- `static-prototype/`: the hand-built prototype the Astro site was rebuilt from (one `index.html`, `styles.css`,
  `assets/js/`, and the six use cases as standalone pages in `use-cases/`). `npm run reference` serves it on port
  4174, and `npm run test:parity` compares the live sections against it.
- `wave.html`: the original dot-wave experiment behind the hero ripple.
- `about-section-demos/`: early concepts for the about section.
